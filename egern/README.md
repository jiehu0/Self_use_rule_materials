# Egern 策略出口小组件

展示两个自选策略组当前实际使用的出口地区、IP、ASN、ISP 和探测延迟。

小号、中号、大号和锁屏组件使用独立布局；macOS 横向组件使用低高度紧凑列表，避免标题或卡片被裁切。

## 安装

在 Egern 中进入“工具 → 模块”，添加以下模块 URL：

```text
https://raw.githubusercontent.com/jiehu0/Self_use_rule_materials/main/egern/policy-exit-widget.yaml
```

打开模块详情，在“展示分组 1”和“展示分组 2”中填写 Egern 里的完整策略组名称。默认值为“策略选择”和“人工智能”。

启用模块后，进入“分析 → 小组件画廊”，添加“策略出口”小组件，再将 Egern 小组件添加到桌面。

## 限制

Egern 的公开脚本 API 暂未提供读取策略组所选节点名称的接口。此组件会分别通过两个策略组访问 IP 信息服务，展示每个分组实际生效的出口信息，而不是 Egern 策略页面中的完整节点名称。

模块详情页的输入框无法自动枚举当前配置中的策略组；分组名称需要手动填写，并且必须与 Egern 中的名称完全一致。
